# Shixun12 Autonomous Local QA

@QA_AUTOTEST.md

## 当前工作区结构

当前目录应为 `shixun12`，其中包含两个独立 Git 仓库：

- `shixun12_backend`
- `shixun12_frontend`

必须把它们视为同一个完整系统进行理解、启动和验收。

## 启动规则

收到用户的“开始自主验收”指令后：

1. 立即阅读 `QA_AUTOTEST.md`。
2. 不要先追问用户项目做什么；必须从文档和代码自行理解。
3. 不要直接在当前原项目运行、安装、构建、生成测试或修改配置。
4. 先把整个 `shixun12` 复制到系统临时目录的独立副本。
5. 后续所有操作只能发生在临时副本。
6. 临时副本必须同时包含前端与后端，并保留当前未提交代码。
7. 禁止访问生产后端、生产数据库、生产账号和真实第三方业务服务。
8. 能本地执行的流程必须实际执行，不能只输出测试计划。
9. 用户无需逐项告诉你测试什么；你必须自己发现功能、动作、流程、状态与边界。
10. 最终在对话中输出测试覆盖、确认 Bug、复现步骤、证据和未验证部分。

除非存在会直接威胁原项目或线上环境的风险，否则不要停下来等待用户确认。
