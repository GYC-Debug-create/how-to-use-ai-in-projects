# 斗罗大陆·武魂觉醒 — 全面提升计划

## 概述

将现有的文字RPG游戏从"功能完整"提升至"体验卓越"级别。涵盖视觉引擎、战斗系统、进度系统、叙事引擎、音频系统、地图探索、品质打磨七大工作流，共计 **32项重大改进**。

---

## 现状分析

### 项目架构
- **后端**: Express.js (`server.js`) 提供静态服务 + 存档API
- **主游戏**: 文字RPG (`game.html` + `game.js` 70KB + `game-data.js` 63KB + `game-events-expanded.js` 261KB)
- **图鉴**: 6标签页百科 (`codex.html` 64KB)
- **地图**: 可拖拽缩放交互地图 (`map.html` 25KB)
- **数据**: 10个JSON文件，~650KB游戏数据
- **资源**: ~190张AI生成图片

### 核心优势
- 武魂人格系统 + 命运路线系统已有基础
- 168个武魂专属事件 + 600+通用事件
- 50+武魂、30魂兽、31魂骨、33人物、26地点的完整图鉴

### 关键短板
1. **视觉**: 无粒子效果、无战斗特效、转场生硬、标题屏单调
2. **战斗**: 仅攻击/技能/道具/逃跑，无元素克制、无连击、无状态效果
3. **进度**: 无技能树、无魂骨锻造、无成就系统、无挑战模式
4. **社交**: 无NPC好感度、无支线任务板、无对话分支
5. **音频**: 完全没有声音系统
6. **地图**: 无战争迷雾、无随机遭遇、无快速旅行
7. **品质**: 无设置菜单、无新手引导、无统计面板

## 改进方案

### 工作流一：视觉引擎革新

#### 1.1 粒子系统框架
- **文件**: `public/game.html` (内联JS)
- **内容**: 创建轻量级Canvas粒子引擎 `ParticleEngine`
  - 支持发射器(emitter)、粒子生命周期、重力、渐变色
  - 预设特效: 灵力光点、火焰余烬、冰晶飘落、雷电弧光、神圣金光
  - 全局背景粒子层(浮空灵力微粒)
  - 战斗特效层(技能释放时的粒子爆发)

#### 1.2 战斗视觉反馈系统
- **文件**: `public/game.html` (CSS + JS)
- **内容**:
  - 浮动伤害数字(暴击金色放大、普通白色、治疗绿色)
  - 屏幕震动效果(重击/暴击时CSS shake动画)
  - 闪光遮罩(技能释放时全屏闪白/闪色)
  - 敌人受击闪烁(红色flash)
  - 血条破碎效果(血量低于25%时血条抖动+红光)
  - 击杀慢动作(敌人消失时scale+fade延迟)

#### 1.3 场景过渡动画
- **文件**: `public/game.html` (CSS + JS)
- **内容**:
  - 卷轴展开式过渡(左右向中间合拢再展开)
  - 墨韵扩散过渡(从点击位置扩散墨色圆)
  - 灵力流转过渡(金色光线扫过屏幕)
  - 随机选择过渡风格避免重复

#### 1.4 标题屏电影级开场
- **文件**: `public/game.html` (CSS + JS)
- **内容**:
  - Logo逐字浮现动画(每个字依次scale+glow)
  - 背景灵力粒子流(持续飘动的金色光点)
  - 浮动符文阵列(半透明古风符文缓慢旋转)
  - 按钮 hover 时灵力涟漪扩散
  - 标语打字机效果

#### 1.5 属性面板动态化
- **文件**: `public/game.html` (CSS + JS)
- **内容**:
  - 武魂图标光环旋转(悬停加速)
  - 血条/魂力条渐变流光动画
  - 属性数值变化时的弹跳+闪光
  - 魂环槽位点亮动画(获得新环时光波扩散)
  - 命运值变化时紫色脉冲

### 工作流二：战斗系统革命

#### 2.1 元素克制系统
- **文件**: `public/game.js` + `public/game-data.js`
- **内容**:
  - 六大元素: 金、木、水、火、土、雷
  - 克制关系: 金克木、木克土、土克水、水克火、火克金、雷克所有(弱)
  - 每个武魂分配主元素(根据type/subtype自动推断)
  - 每个魂兽分配元素属性
  - 克制时伤害×1.5，被克时×0.7
  - 战斗界面显示元素图标和克制提示

#### 2.2 连击与暴击系统
- **文件**: `public/game.js`
- **内容**:
  - 连续攻击不中断时累积连击数(combo)
  - 连击5/10/20层时伤害递增(×1.1/×1.25/×1.5)
  - 暴击率 = 基础5% + 速度差×0.5% + 连击层×1%
  - 暴击伤害×1.8，金色伤害数字
  - 连击数显示在战斗界面顶部

#### 2.3 状态效果系统
- **文件**: `public/game.js` + `public/game-data.js`
- **内容**:
  - 燃烧(每回合损失最大HP的3%，持续3回合)
  - 冻结(无法行动1回合，受雷击解除)
  - 中毒(每回合损失固定值，持续5回合)
  - 狂暴(攻击+30%，防御-20%，持续3回合)
  - 护盾(抵消下次伤害的50%)
  - 魂技附带状态效果，部分魂兽攻击附带状态

#### 2.4 Boss战机制
- **文件**: `public/game.js` + `public/game-data.js`
- **内容**:
  - Boss分阶段(100%~60%阶段1，60%~30%阶段2，30%~0%阶段3)
  - 阶段切换时释放特殊技能(全屏AOE、召唤小弟、狂暴)
  - Boss怒气条(受到伤害累积，满后释放大招)
  - 每个阶段有不同的战斗对话
  - 封号斗罗级Boss有独特机制(反伤、闪避、吸血)

#### 2.5 自动战斗与倍速
- **文件**: `public/game.js` + `public/game.html`
- **内容**:
  - 自动战斗AI(优先技能→普攻→道具→逃跑)
  - 1x/2x/3x战斗速度切换
  - 自动战斗时跳过等待延迟
  - 可随时手动接管

### 工作流三：深度进度系统

#### 3.1 技能树可视化
- **文件**: `public/game.html` (新增弹窗) + `public/game.js`
- **内容**:
  - 每个武魂类型有专属技能树(3条分支: 攻击/防御/辅助)
  - 技能点获取: 升级1点 + 完成成就1点
  - 被动技能节点(属性加成) + 主动技能节点(新魂技)
  - 树状SVG可视化，已学节点金色发光，可学节点脉冲
  - 前置依赖关系(需学A才能学B)

#### 3.2 魂骨锻造系统
- **文件**: `public/game.html` (弹窗) + `public/game.js` + `public/data/bone-codex.json`
- **内容**:
  - 消耗金币 + 材料(战斗掉落)升级魂骨等级(+1~+10)
  - 每级提供属性加成递增
  - 套装效果(同源魂骨2件/4件激活额外属性)
  - 锻造失败率(高等级有碎裂风险，可用保护符)
  - 锻造界面: 选择魂骨→显示当前/下一级属性→消耗预览→锻造动画

#### 3.3 成就系统
- **文件**: `public/game.js` + `public/game-data.js`
- **内容**:
  - 50+成就分5类: 战斗、探索、修炼、社交、特殊
  - 示例: "初出茅庐"(首胜)、"百战不殆"(100胜)、"元素大师"(使用所有元素克制)
  - 成就解锁时全屏成就横幅+音效
  - 成就奖励: 金币、技能点、命运值、特殊道具
  - 成就面板可从主菜单查看

#### 3.4 称号系统
- **文件**: `public/game.js` + `public/game-data.js`
- **内容**:
  - 20+称号通过成就/事件/等级解锁
  - 称号提供被动属性加成
  - 示例: "星斗守护者"(防御+10)、"杀戮之王"(攻击+15)
  - 状态面板显示当前称号，可切换
  - 称号显示在角色名旁边

#### 3.5 挑战塔模式
- **文件**: `public/game.html` (弹窗) + `public/game.js`
- **内容**:
  - 50层无尽塔，每层随机魂兽组合
  - 每5层Boss层，每10层奖励层
  - 层间不恢复HP/魂力(策略性资源管理)
  - 每日可挑战1次，记录最高层数
  - 排行榜(本地存储)
  - 通关50层获得专属称号

#### 3.6 日常签到与奖励
- **文件**: `public/game.js`
- **内容**:
  - 每日首次登录签到
  - 连续签到7天递增奖励(金币→道具→技能点→稀有道具)
  - 每日3个随机任务(击杀X只魂兽、探索X个地点、使用X次技能)
  - 完成任务获得额外奖励

### 工作流四：叙事引擎增强

#### 4.1 NPC好感度系统
- **文件**: `public/game.js` + `public/data/npc-codex.json`
- **内容**:
  - 每个NPC有好感度等级(0~100，分5阶: 陌生/相识/友好/知己/生死之交)
  - 通过事件选择、赠礼、共同战斗提升好感
  - 好感度达到特定等级解锁专属事件和奖励
  - 高好感NPC可在战斗中助战(每场1次召唤)
  - NPC面板显示好感度进度条和已解锁内容

#### 4.2 支线任务板
- **文件**: `public/game.html` (弹窗) + `public/game.js` + `public/game-data.js`
- **内容**:
  - 每个地点有可接取的支线任务(2~4个)
  - 任务类型: 击杀类、收集类、护送类、探索类
  - 任务有等级推荐和奖励预览
  - 同时最多接取5个任务
  - 任务追踪显示在状态面板
  - 完成任务后回到接取地点交付

#### 4.3 事件日志/冒险日记
- **文件**: `public/game.html` (弹窗) + `public/game.js`
- **内容**:
  - 自动记录关键事件(战斗、升级、奇遇、成就)
  - 按时间线分类(学院篇/冒险篇/封号篇/成神篇)
  - 每条记录含时间、地点、事件名、结果
  - 可从主菜单查看完整冒险日记
  - 支持搜索和筛选

#### 4.4 多结局深化
- **文件**: `public/game.js` + `public/game-data.js`
- **内容**:
  - 每条命运路线有3种结局(好/中/差)，共15种
  - 结局由: 命运路线 + 最终等级 + 关键选择 + 好感度 共同决定
  - 每种结局有独特的结尾叙事和统计
  - 解锁的结局在主菜单可回看
  - 隐藏结局(满足极其苛刻的条件)

## 假设与决策

### 技术约束
- **保持单文件纯前端**: 所有新增系统内联到现有HTML文件中，不引入框架/CDN
- **不使用外部音频文件**: 音频全部通过Web Audio API程序化生成
- **不使用外部图片**: 新增视觉元素通过CSS/SVG/Canvas实现
- **保持中文全量**: 所有新增文本、路径、变量名保持中文

### 设计决策
- **视觉风格**: 延续暗褐+金叶的古风卷轴风格，增加层次感和动态感
- **战斗节奏**: 默认速度适中，提供加速选项，确保不拖沓
- **进度曲线**: 新系统(技能树/锻造)提供额外成长维度，但不取代现有等级系统
- **兼容性**: 新增功能对旧存档向后兼容，缺失字段使用默认值

### 优先级排序
1. **P0 (核心体验)**: 粒子引擎、战斗特效、元素系统、状态效果、技能树、成就系统
2. **P1 (深度内容)**: Boss战、挑战塔、NPC好感度、支线任务板、音频系统
3. **P2 (沉浸感)**: 场景过渡、标题动画、战争迷雾、随机遭遇、快速旅行
4. **P3 (品质)**: 设置菜单、新手引导、统计面板、性能优化、存档安全
