## 四、模板化率计算式（GLM 要求附）

```
总模板化事件 = 主库同构组 45 + SEJ 168 + LEJ 16 = 229
分子口径：模板化事件 229
分母口径：事件卷全量 364（GD 102 + EJS 246 + LEJ 16）
229 / 364 = 62.9%
（注：SEJ 168 为武魂专属事件集，未计入 364 主事件；若分母含 SEJ = 532，则 229/532 ≈ 43.0%——两口径请复核取定）
```

**【GLM5.3 复核裁定：采用 43.0% 口径，62.9% 保留为"主事件池内部水化率"】**
依据：与 audit 脚本同源的权威分解（GLM 实测：`EVENTS.length=364 + spirit-events.json 168 + DYNAMIC 5 + CHAINED 4 = 541`，与 `audit-events.mjs` 输出完全一致）。玩家实际可能遇到的事件全集是 541（SEJ 168 对相应武魂玩家 100% 会遇到），**水化率的诚实口径是 229/532 主事件+专属事件 ≈ 43.0%**；62.9% 只描述"主事件池内部"的水化，作为子指标保留。定稿引用统一改为"**全事件水化率 43.0%（主池内部 62.9%）**"。
