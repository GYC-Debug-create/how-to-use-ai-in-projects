# 玩家预期与剧情逻辑标准（flash 独立版）

> 立场稿（与 GLM5.3 对话迭代用）。视角说明：不从"系统清单"入手，而从
> **文字版玩家的"时刻体验"**入手——文字 RPG 的每一分钟就是
> 「读一段 → 做一个选择 → 看一个结果」的循环。所以我的标尺全部围绕：
> 玩家在读的时候，世界是否自洽；选的时候，选择是否有意义；看结果的时候，
> 结果是否配得上文本。

---

## 〇、先立第一性：文字版玩家到底在消费什么

一个斗罗读者点开文字 RPG，他要的不是"数值成长"，是**"我在斗罗世界里活过一段"**。
文字版唯一能给的沉浸感来源有三个，缺一不可：

1. **读得通**：文本描述的世界符合他脑子里的斗罗（魂力体系、武魂、魂环年限、魂师身份、势力格局）
2. **选得动**：每个选择都让他觉得"这里真的需要我拿主意"，且后果看得见
3. **记得住**：他做过的事会在世界里有回响（NPC 记住他、地点变化、日记/图鉴/名分记录他）

任何系统设计，如果破坏这三条中的任何一条，就是"感觉不对"。

---

## 一、世界自洽标准（读得通）

### 1.1 身份与内容必须同段位
- 什么身份遇到什么事：魂士的烦恼是食堂、入学、第一只魂兽；魂尊的烦恼是大赛、宗门、千年魂兽；封号斗罗的烦恼是势力博弈、十万年魂兽、神位。
- **禁止"身份错位事件"**：封号斗罗再回食堂抢红烧肉、魂士遇见封号斗罗级势力阴谋、41 级就号称"神途"。
- 名分（称号）必须被世界承认：魂尊出去办事，事件文本里 NPC 的态度、遇到的对手强度、奖励量级都要匹配。

### 1.2 时间与因果必须成立
- 事件有先后：先入学后考试、先历练后成名、先结识后告别。同一个剧本里不能今天"第一堂课"明天"期末大考"后天又"第一堂课"（unique 之外的同段位事件也要有隐含的时间梯度）。
- 昼夜、季节、天气是世界的时钟：夜间抽到"中午的食堂"就是穿帮；暴雨天出"晴空万里"的文本就是穿帮。
- 地点是事件的舞台约束：学院事件在学院、森林事件在森林；跨地点事件必须有"去了"的前提（旅行/到达）。

### 1.3 人物身份必须符合原著设定
- 原著人物出现时，身份、年龄、立场必须符合原著时间线。
- **原著主角团与玩家的关系**：同侪（同期同学/同龄魂师）可以，导师/学长/长辈不可以——玩家是主角，原著主角不能凌驾于玩家之上，也不能把玩家变成"小师弟"视角。
- 人物行为要符合人设：大师是理论型导师不是白发老翁；小舞不会随便送人"十万年祝福"；武魂殿的转变要有过程（官方→反派）。

### 1.4 数值与叙事不得打架
- 文本说"千年魂兽"，战斗难度与奖励就得是千年档；文本说"十万年"，就不能只是 heal 999 的道具掉落——文本的敬畏感与数值的含金量必须一致。
- 稀缺性叙事要有稀缺性数值：原著里十万年魂环是传说，游戏里就不能烂大街。
- 奖励来源要合理：谁给的、为什么给、给多少，都对得上。

## 二、选择意义标准（选得动）

### 2.1 选择要有"信息差之前的决策感"
- 玩家做选择时，要么知道代价（明示消耗/风险），要么能从文本推断（暗示后果）。
- **"无信息选择"是可接受的**（人生就是盲选），但**"无后果选择"不可接受**——选了 A 和选 B 结果一样，就是假选择。

### 2.2 选择后果要有"回响"
- 短期回响：结果文本、数值变化、状态变化（立即可见）。
- 中期回响：NPC 态度、地点变化、后续事件分支（做过的选择被世界记住）。
- 长期回响：结局、称号、命运值、势力立场（最终清算）。
- 回响不必每次都大，但必须存在——玩家需要能说出"因为我当初选了 X，所以现在 Y"。

### 2.3 失败要有"教训"而不是"白干"
- 单机文字版对惩罚的耐受度低，但"零代价重试"会毁掉仪式感。
- 失败的正确形态：**损失资源/时间，但获得信息或教训**（猎环失败知道这只魂兽的强度、战斗失败知道敌人的弱点、事件失败获得经验）。
- 禁止：失败后无任何产出、失败后卡死无出路、失败惩罚与文本不匹配（摔一跤扣 1000 金币）。

---

## 三、世界记忆标准（记得住）

### 3.1 玩家的历史必须被记录并可见
- 日记、图鉴点亮、猎魂简记、称号墙、成就——任何"我做过的事"都要有可见的档案。
- 图鉴必须是"收集进度"而非"静态百科"：见过/未见过、猎过/未猎过、结识/未结识，一目了然。

### 3.2 世界的状态必须反映玩家的行为
- 帮助过的人会回报、背叛过的人会记仇、破坏过的势力会敌视。
- 势力关系（武魂殿/宗门/帝国）可以是一条简单的数值线，但必须存在且可见——"世界是活的"不需要复杂系统，只需要"记得"。

### 3.3 存档与信任
- 存档是玩家对游戏的信任投票：绝不静默覆盖、冲突必须显式选择、进度必须有备份与可见性。

## 四、对经济与养成系统的立场（原著弱对应区，最容易被做成"独立小游戏"）

1. **修炼/锻造/签到/商店必须服务于成长叙事**，不能是脱离剧情的数值刷子：
   - 修炼 = "闭关/苦修"的叙事化（有事件、有代价、有瓶颈感），不是点一下 +X 经验
   - 锻造 = 魂骨/装备的来历要有故事（材料来自哪只魂兽、哪位匠人），不是材料条
   - 签到 = 原著没有，必须包装成世界内行为（宗门的月俸、武魂殿的津贴），不能是"登录奖励"裸奔
   - 商店 = 魂师也需要补给，但商品要符合魂师世界（丹药/卷轴/材料），价格体系要防通胀
2. **金币/命运值的意义**：金币是魂师世界的通用货币（有合理流向）；命运值是"选择的重量"（有可见的累积与消费）。

## 五、文字版边界声明（不苛求项）

- 不苛求：实时战斗/动作演出/多人/动画/配音/大地图自由移动。
- 文字版必须做到的底线：**文本即世界**（所有系统信息都以"世界内语言"呈现）、**选择即行动**（选项之间真的有差别）、**结果即回响**（付出与回报对得上）。
- 单机：可以没有社交，但 NPC 必须像活人（记得、回应、有自己的目的）。

## 六、我对 GLM 四个"拿不准点"的独立立场

### 1. 无限重摇觉醒
- 原著一次觉醒，但游戏开局友好性需要退让。我的倾向：**默认一次觉醒 + 可重摇但有代价**。
- 代价形态建议：不是金钱，而是**时间与稀缺性**——重摇消耗游戏内时间（错过剧情）或消耗"命运机会"（有限的命运重开次数）；神级/高品质需要保底但保底要"看得见的进程"。
- 关键不是"能不能重摇"，而是"重摇这个行为在剧情里说得通"：可以是"武魂殿二次觉醒仪式（剧情奇遇）"，而不是标题页一个免费按钮。

### 2. 原著主角团的处理
- 我的立场：**同期同侪 + 克制 cameo**。唐三小舞可以是"同届同学"，玩家与他们平起平坐、互相竞争/合作，但：
  - 不能是学长/导师（身份错位，已违反 1.3）
  - 不能抢玩家的戏（玩家的高光时刻玩家自己完成）
  - 原著主角的"传奇感"要保留（他们有自己的故事线在背景里发生，玩家偶尔听闻）
- 玩家期待的其实是"和主角同代"的参与感，不是"被主角罩着"的旁观感。

### 3. 失败重试的边界
- 标尺：**失败有代价，代价 = 资源/时间；失败有产出，产出 = 信息/教训；重试是"带着教训再来"而不是"原点重来"**。
- 具体到猎环：失败 → 扣时间/少量资源 + 获得"这只魂兽的弱点信息"（下次猎它更容易/可以换目标）；魂兽本身可以重猎（原著魂兽是资源不是副本 Boss）。
- 挫败感来源是"无意义重复"；接受度来源是"每次失败都在推进我（哪怕只是信息）"。

### 4. 判例集盲区补充（我补的类别）
- **身份-等级错位**（低身份遇高级事/高身份遇低级事）
- **时间/昼夜/天气穿帮**（中午的食堂出现在深夜）
- **原著人物身份错位**（唐三当学长）
- **数值-叙事超模**（十万年祝福=heal 999）
- **无后果假选择**（A/B 结果一样）
- **失败白干**（重试零信息增量）
- **经济通胀/商店存在感**（钱没处花或钱不值钱）
- **图鉴不认账**（收集无进度感）
- **世界不记得**（NPC 转头就忘）
- **阶段节奏水化**（后期高频低权重日常刷屏）

---

## 七、一句话总结我的标尺

**文字版斗罗的合格线 = 世界自洽（身份/时间/人物/数值都对得上）× 选择有意义（有信息差、有回响、失败有教训）× 世界记得住（历史可见、状态反映、存档可信）。**

任何一处"对不上"，就是玩家说的"感觉不对"。
