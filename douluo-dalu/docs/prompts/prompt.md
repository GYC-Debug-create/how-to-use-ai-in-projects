## P0 — 必须首先修复

### P0-01 保存成功后无法继续冒险
现象：存档提示成功 → 返回 `#/title` → 点"继续冒险"无反应、不恢复角色、无失败提示。
修复：
1. 核对本地/服务器存档的保存与读取结构，统一字段。
2. 核对 `playerId` 保存与恢复；返回标题页不得误清当前 ID。
3. 核对标题页"继续冒险"事件绑定与 hash 路由。
4. 旧档迁移后仍可继续；本地与服务器存档有明确优先级与失败回退。
5. 读取成功真正进入 `#/game` 并恢复状态栏/场景/剧情。
6. 读取失败在标题页明确报错（如"没有找到可继续的存档"/"存档数据损坏，已尝试恢复备份"/"服务器读取失败，已使用本地存档"）。禁止点击后静默停留。
验收：临时角色 → 推进剧情 → 改等级/金币/位置 → 保存 → 回标题 → 继续冒险恢复同一角色 → 刷新后再继续仍恢复（名字/等级/金币/位置/魂环/剧情一致）。补回归测试覆盖：保存 → 回标题 → 继续 → 刷新 → 再继续。

## P1 — 核心功能

### P1-02 地图地点无法鼠标点击
现象：能看到地点标记，但鼠标点击无反应，仅键盘 Enter 可用。
修复：真实宽高、z-index、pointer-events、父容器尺寸、iframe 拦截、鼠标/触摸/键盘同一套逻辑，图标与文字都绑定点击。验收：鼠标点图标与文字、触摸、Enter/Space 均可开详情；用真实鼠标坐标点击验证，不要只调 `element.click()`。

### P1-03 地点名称不统一
现象：主线"星斗大森林外围"、路线"史莱克学院 → 星斗大森林外围"、地图"星斗大森林"、事件"星斗大森林·外围"。
修复：主线/地图/旅行/事件/当前位置/日记/存档统一使用稳定地点 ID；子区域明确建模（"星斗大森林·外围"或"星斗大森林 > 外围"）；兼容旧档旧 ID；旅行后 `G.location`、主线目标、地图位置、旅行记录、事件地点、日记一致；玩家不会被要求去地图上不存在的地点。验收：Lv.5"第一次猎杀"出现时地图有可操作目标地点，旅行后主线显示已到达。

### P1-04 边境小城"铁剑"不可见
现象：出身说明"开局获得武器「铁剑」（攻击+5）"但背包没有。
修复（二选一，必须闭环）：
- 方案A：真实发放铁剑，背包/装备面板可见，显示攻击+5，保存读档后仍在，属性显示来源。
- 方案B：改文案为"边境训练使攻击力+5"，存为出身被动，在觉醒结果/角色面板显示"出身加成：边境训练 +5 攻击"，实际攻击确实 +5。
禁止留下"文案说有、玩家找不到"的半成品。

### P1-05 武魂觉醒预览属性与确认后不一致
现象：预览与确认属性不同（如 攻击34/防御18/生命270/速度14 → 攻击40/防御19/生命238/速度15）。
修复：预览与确认调用同一基础属性函数；明确区分武魂基础/出身加成/先天魂力/天赋/装备/最终属性；若变化是设计行为必须在界面展示明细；角色面板生命与实际 `G.hp`/最大生命一致。验收：四种出身各测一次，加属性计算回归测试。

### P1-06 满血使用回魂丹仍消耗道具
修复：用生命恢复道具前判断当前生命 < 最大生命；满血时按钮禁用或提示"当前生命已满"，绝不扣数量；非满血时显示实际恢复量；统一战斗内外逻辑；检查全恢复/魂力恢复等其他治疗道具。验收：满血数量不变、非满血扣减且恢复正确、加自动测试。

### P1-07 Lv.5"第一次猎杀"无魂环解释
现象：魂环门槛 Lv.10，但 Lv.5 主线写"猎杀十年魂兽"，胜利后无魂环。
修复：保留 Lv.10 门槛，将该战斗改为"魂兽实战训练"（标题与正文明确：未达 Lv.10、训练性质、不产生/吸收魂环）；胜利结果明确提示"实战训练完成，达到 Lv.10 后可正式猎取第一魂环"；不走正式魂环奖励逻辑；战后目标指向修炼至 Lv.10 或准备第一魂环，不能跳到 Lv.20 魂师大赛；不许偷发魂环掩盖。

### P1-08 战斗经验显示与实际变化不一致
现象：经验 86/255，胜利文字 +94，实际变 200/255（+114）。
修复：审计所有经验来源（战斗/事件/任务/成就/连锁/隐藏）；检查 `applyResultRewards()` 是否重复调用；战斗胜利/事件完成/成就是否重复发放；用结构化奖励结果，结果页显示明细（战斗+任务+成就+其他+总计），总计必须等于实际变化；跨等级显示升级前后与溢出；同一事件不重复领取。加测试：前值/各项/后值/各项之和=实际变化。

### P1-09 新手引导在剧情中途突然阻塞
修复：引导只在首次进入后的安全时机出现；有剧情选项/魂环选择/战斗中/有其他弹窗/播放剧情时禁止弹出；弹出前暂停剧情；提供开始/跳过/稍后再看；跳过后续不再自动弹，可从帮助或设置手动查看；关闭后恢复剧情不丢选择；弹出时清理过期 Toast 与成就通知。

### P1-10 NPC 结识提示持续残留
现象："结识了『玉小刚』！人物图鉴已更新"反复出现。
修复：NPC 解锁不重复写入；不残留全局未消费通知；`renderScene()` 不复用上一事件通知；日记与瞬态 Toast 字段分离；新事件开始时清理上一事件提示。验收：只出现一次，后续仅保留在日记/图鉴/关系面板，加回归测试。

### P1-11 成就/升级通知与顶部菜单遮挡内容
修复：成就/升级/NPC 解锁/地点发现/Toast/旅行反馈统一进队列，同一时间最多一条主通知；通知不覆盖事件标题/正文/选项/战斗按钮/魂环按钮；用正文前内容流或固定不遮区；顶部菜单点击功能后自动收起，旅行完成自动关闭；剧情选择或战斗时无并行遮挡通知；移动端与桌面端验证；保留无障碍语义与键盘操作。

### P1-12 出身没有统一世界状态
现象：四种出身只改开场文字与初始属性，之后汇入同一条路线。
修复：存档稳定保存 `origin`；角色面板/日记显示出身；地图或地点记录体现出生地；每种出身至少一个持续影响（出生地探索记录/专属 NPC/专属早期事件/起始资源/事件权重/称号/显式属性被动），保存并在读档后恢复。不要求四条独立主线，但不能只影响开场文字。

## P2 — 成长、内容与界面

### P2-13 Lv.5 → Lv.10 目标空档
修复：Lv.5 后显示"当前目标：修炼至 Lv.10"；状态区显示当前等级、距 Lv.10 差值、推荐行动、修炼入口、第一魂环解锁时机；Lv.10 进入第一魂环流程，获得后才显示 Lv.20 主线；主线/门槛/地图目标/行动按钮同步；旧高等级存档不被强制倒放新手剧情。

### P2-14 NPC 关系缺冷却与长期反馈
修复：今日互动次数或明确冷却状态；互动后显示"今日已互动/下次可互动时间/条件"；好感阶段解锁新内容（对话/任务/帮助/道具/事件）；关系变化不止数字；关系状态保存并读档恢复；优先用已有游戏日/事件计数/时间系统，不引入无法保存的临时计时器。

### P2-15 早期选择无长期后果
修复：用现有事件条件与结果字段，让早期 A/B/C 选择至少产生一个可感知影响（后续 NPC 对话不同/事件权重不同/解锁线索/称号/起始资源/学院阶段不同反馈/任务条件或奖励不同）；玩家能在后续事件、日记、面板或 NPC 关系中看到选择被记住。

### P2-16 响应式布局
必须验证视口：390×844、844×390、768×1024、1366×768、1920×1080。
要求：无横向溢出；标题/正文/选项/继续按钮不重叠；移动端状态面板默认折叠或紧凑；场景图不挤压正文选项；选项可自然滚动到达；新事件必要时自动滚动到操作区；桌面侧栏不撑大主场景；通知不遮按钮；横屏手机可看到/滚到完整选项。

### P2-17 隐藏地点无发现规则
修复：为隐藏地点提供玩家可理解线索，至少显示一项：所需等级/任务/NPC 线索/时间/天气/道具/推荐战力/当前已知线索；可隐藏完整条件但不能只显示内部 ID 或完全无提示；地点详情、帮助、主线提示规则一致。

### P2-18 内部字段直接展示给玩家
修复：统一转换 `epic→史诗`、`legendary→传说`、`divine→神级`、`none→无/未发现/不适用`；检查魂骨图鉴、统计面板、魂技详情、武魂详情、地图详情、事件奖励、空值与内部 ID；魂骨图鉴"0/31"必须说明当前收集数、总数含义、获取来源、未解锁条件或线索。

## P3 — 开场跳过反馈
