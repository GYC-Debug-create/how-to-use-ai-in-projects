# 斗罗大陆·文字修仙 RPG 全前端重写 Prompt

请基于以下现有的后端和数据资源，将整个游戏从"类我的世界像素RPG"**完全重写为文字修仙/文字冒险RPG模式**。面向用户是**10岁左右的小朋友**，要通俗易懂、有代入感、操作简单。

---

## 一、后端环境（保持不变）

- **Express 服务器** `http://localhost:3000`，`express.static` 托管 `public/`
- 已有 API 路由：
  - `POST /api/player/save` — 存档 `{playerId, data}`
  - `GET /api/player/load/:playerId` — 读档
  - `GET /api/player/list` — 存档列表
  - `DELETE /api/player/:playerId` — 删档
  - `GET /api/spirits` — 武魂数据
  - `GET /api/beasts` — 魂兽数据
- 静态数据文件：
  - `/data/spirit-codex.json` (70个武魂，含 image/attack/defense/hp/speed/maxLevel/tier/traits/desc 等字段)
  - `/data/beast-codex.json` (30个魂兽，含 habitat/ringColor/specialAbility 等字段)
  - `/data/ring-codex.json` (12种魂环，含 statBonus/dropRate/sourceBeasts/absorptionRisk 等字段)
- 图片资源：`/assets/spirits/*.jpg` (70张), `/assets/beasts/*.jpg` (30张), `/assets/rings/*.jpg` (12张)
- 现有的 `index.html`（像素RPG版本）保留不动，新游戏用新文件名

1. **`game.html`** — 新的文字RPG游戏主页面（纯单文件，内联CSS+JS）

## 三、游戏流程设计（Lv.0 → Lv.100）

### 3.1 开篇（Lv.0-1）
- **标题画面**: "斗罗大陆·武魂觉醒"，古朴卷轴风格背景
- **主菜单**: 
  - "新游戏" → 进入创建角色
  - "继续冒险" → 读取存档
  - "万象图鉴" → 跳转到 `/codex.html`
- **创建角色**:
  - 输入角色名（2-8个字）
  - 选择出身（影响初始属性和剧情对话）:
    - 星斗大森林旁的小村庄（属性均衡）
    - 武魂城世家子弟（初始魂力高，武魂品质权重+10%）
    - 天斗帝国边境小城（初始获得低级武器）
    - 海神岛渔村（速度偏高的水系天赋）
  - **武魂觉醒仪式**: 根据出身随机抽取武魂，但给玩家3次"重新觉醒"的机会
    - 低级武魂概率: 40%
    - 中级武魂概率: 35%
    - 高级武魂概率: 18%
    - 顶级武魂概率: 6%
    - 神级武魂概率: 1%
    - （出身"武魂城"可额外+10%提升一档的概率）
  - 觉醒动画: 屏幕中央大图展示武魂 + 文字描述（用 spirit-codex.json 的 desc 字段）
  - 确认后进入游戏

### 3.2 成长体系（Lv.1-10 学院篇）
- **场景**: 史莱克学院 / 天斗学院（根据选择）
- 每升一级需要通过一个"事件":
  - **课堂学习**: 选择偏重攻击/防御/速度，影响属性成长比例
  - **食堂趣事**: 随机事件，可能获得buff或debuff（搞笑向）
  - **操场对练**: 与NPC对战，文字描述+选择行动
  - **森林历练**: 遇到野生魂兽，选择战斗/逃跑/观察
- Lv.10时触发**第一个魂环获取**: 
  - 进入星斗大森林
  - 选择猎杀的十年魂兽（3选1）
  - 吸收成功获得第一个魂技（根据武魂类型随机生成技能名和效果）
  - 吸收失败（极低概率）则延迟到Lv.12

### 3.3 中期成长（Lv.11-40 实战篇）
- 每5级左右触发一个主线剧情事件:
  - **魂师大赛**: 与对手对战，胜利获得大量经验和稀有奖励
  - **武魂殿考核**: 答题+战斗混合，通过可获得特殊魂环
  - **魂兽暴动**: 紧急事件，保护村庄/学院，选择策略影响结局
  - **遇见伙伴**: 随机遇到NPC队友，可获得临时加成
  - **奇遇**: 随机事件，可能获得:
    - 隐藏武魂进化（低级→中级，中级→高级）
    - 特殊魂技
    - 属性大幅提升
- 每10级获得一个新魂环:
  - Lv.20: 百年魂环（从3只百年魂兽中选择）
  - Lv.30: 千年魂环（从3只千年魂兽中选择）
  - Lv.40: 万年魂环（从2只万年魂兽中选择）

### 3.4 高级阶段（Lv.41-70 封号篇）
- 主线剧情:
  - **封号斗罗的挑战**: 与强敌对战，胜利获得封号
  - **武魂殿的秘密**: 揭露阴谋，选择站队（影响后续剧情）
  - **十万年魂兽的邂逅**: 遇到可以化形的魂兽，选择战斗/结交
  - **修炼瓶颈**: 需要选择突破方式（苦修/奇遇/丹药）
- 每10级获得一个魂环:
  - Lv.50: 万年魂环
  - Lv.60: 万年魂环（可选择特殊魂环如神赐魂环、进化魂环等）
  - Lv.70: 十万年红环

### 3.5 巅峰阶段（Lv.71-100 成神篇）
- 主线剧情:
  - **神位传承**: 通过神之试炼
  - **最终决战**: 与最终BOSS对决（多回合）
  - **结局**: 根据之前的所有选择生成个性化结局
- Lv.80: 十万年红环
- Lv.90: 百万年金环 或 神赐魂环
- Lv.100: 达到神级，游戏通关，展示战斗统计和结局故事

### 3.6 事件选择系统
每个事件都是一段文字描述 + 2-4个选项:
```
【星斗大森林·深处】
你穿过浓密的灌木丛，忽然听到一阵低沉的咆哮声。
一只浑身火红的百年烈焰虎正盯著你，眼中满是敌意。

A. 正面迎战！[需要战斗力 > 30]
B. 使用魂技先发制人 [消耗魂力20]
C. 尝试绕过它 [需要速度 > 15]
D. 大声呼救 [随机结果]
```
- 选择会影响: 经验值、属性、剧情走向、后续可用选项
- 某些关键选择会影响"命运值"，最终影响结局

## 四、核心数据结构

### 4.1 玩家数据（存档用）
```javascript
{
  playerId: "uuid",
  name: "角色名",
  origin: "star_forest",  // 出身
  spirit: { id, name, tier, type, image, desc },
  level: 1,
  exp: 0,
  expToNext: 100,
  stats: { attack: 10, defense: 5, hp: 100, maxHp: 100, speed: 8, spiritPower: 10 },
  rings: [ { level: 1, name: "十年白环", color: "#fff", skill: "缠绕", bonus: {...} } ],
  skills: [ { name: "缠绕", type: "控制", damage: 15, cooldown: 3, desc: "..." } ],
  inventory: [ { name: "回魂丹", type: "heal", value: 50, count: 3 } ],
  gold: 100,
  fatePoints: 0,       // 命运值，影响结局
  currentScene: "academy_classroom",
  choices: { "event_1": "A", "event_5": "C" },  // 历史选择记录
  achievements: [],
  playTime: 3600
}
```

### 4.2 属性计算
- 基础属性 = 武魂基础值 × (1 + level × 0.05)
- 魂环加成 = 所有魂环 bonus 累加
- 最终属性 = 基础属性 + 魂环加成 + 装备加成 + buff加成
- 经验值公式: `expToNext = 100 × level^1.3`

### 4.3 战斗系统（简化版）
- 回合制，文字描述
- 每回合玩家选择: 普通攻击 / 使用魂技 / 使用道具 / 逃跑
- 伤害 = (攻击 - 防御×0.5) × 随机(0.8~1.2)
- 魂技有冷却回合数
- 道具有使用次数

## 五、界面设计

### 5.1 视觉风格
- **古朴卷轴风格**（与 codex.html 保持一致）:
  - 暗褐色底 `#1a1408`，金叶色 `#c9a84c`，墨色文字 `#d4c5a0`
  - 字体: 标题用 Ma Shan Zheng（毛笔书法），正文用 Noto Serif SC
  - 纸张纹理叠加
- **适合小朋友**: 
  - 文字大而清晰，最小字号不小于14px
  - 按钮大（至少 44px 高度），颜色鲜明
  - 重要信息用金色/红色高亮
  - 不要太暗太压抑，可以在古朴基础上适当提亮

### 5.2 页面布局
整个游戏是一个**单页应用**，通过显示/隐藏不同的"场景区域"来切换:

#### 5.2.1 标题画面
- 大标题 + 古风背景
- 三个按钮（新游戏/继续/万象图鉴）

#### 5.2.2 创建角色画面
- 步骤式（step by step）:
  1. 输入名字
  2. 选择出身（4个卡片式选项，带图片和说明）
  3. 武魂觉醒（动画展示 → 3次重抽机会）

#### 5.2.3 主游戏界面
分为三个区域:
- **左侧（或顶部）**: 角色状态面板
  - 头像 + 名字 + 等级
  - 武魂名称和图标（小图）
  - HP条 / 魂力条 / 经验条
  - 魂环显示（最多9个圆环，按颜色）
  - 四维属性: 攻击/防御/生命/速度
  - 金币
- **中央（主要内容区）**: 文字叙事区
  - 场景描述（段落文字，带淡入动画）
  - 事件图片（大图，使用魂兽/武魂的image字段）
  - 选项按钮（2-4个，每个有条件提示）
  - 战斗界面（战斗时替换叙事区）
- **右侧（或底部）**: 操作区
  - "背包"按钮 → 弹出道具列表
  - "图鉴"按钮 → 跳转 codex.html
  - "存档"按钮
  - "设置"按钮（音量等）

#### 5.2.4 战斗界面
- 上方: 敌人信息（名称+大图+HP条）
- 中间: 战斗日志（滚动文字区域，显示每回合发生了什么）
- 下方: 行动按钮（普通攻击/魂技列表/道具/逃跑）

#### 5.2.5 弹窗
- 道具详情、等级提升、魂环获取、存档/读档等

## 八、技术约束

1. **纯原生**: 不使用 React/Vue/任何框架
2. **单文件**（或 HTML + 一个 game.js）: CSS 内联，JS 可拆分
3. **数据来源**: 
   - 武魂/魂兽/魂环数据从 JSON 文件 fetch 加载
   - 事件剧情直接写在 JS 里（内联数据数组）
   - 存档用已有的 `/api/player/save` 和 `/api/player/load` API
4. **图片**: 使用已有的 `/assets/` 下 112 张图片
5. **字体**: 可引入 Google Fonts（Ma Shan Zheng + Noto Serif SC）
6. **响应式**: 优先桌面体验，但平板也能玩
7. **无音效要求**: 暂不需要音效
8. **localStorage 缓存**: 当前游戏状态实时缓存到 localStorage，防止意外关闭丢失

---

## 九、重点提醒

- **面向10岁小朋友**: 文字要生动有趣，不要太阴暗，战斗描述要有画面感但不要血腥，可以加入幽默元素
- **代入感**: 主角是玩家自己创建的角色，不是唐三或其他原著角色。可以遇到原著人物作为NPC（如大师、唐三、小舞等作为学长学姐/对手出现）
- **选择有意义**: 玩家的选择要确实影响后续剧情和结局，不要是虚假选择
- **万象图鉴联动**: 游戏中遇到的武魂/魂兽/魂环，可以在图鉴中查看详细信息
- **可玩性**: 升级有成就感，每升一级都有新内容，不要让玩家觉得在刷等级
